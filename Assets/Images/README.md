# 🌌 Vystra

> **Visualize. Structure. Orchestrate.**

**Vystra**, karmaşık yazılım mimarilerini, API akışlarını ve mantıksal sistemleri somutlaştırmak için tasarlanmış, yüksek performanslı ve estetik bir **Görsel Veri Orkestratörü**dür. Yazılım geliştiricilerin kafasındaki "sürreal" yapıları sürükle-bırak yöntemiyle çalışan interaktif bir tuvale dönüştürür.[cite: 1]

---

## ✨ Temel Özellikler

- 🎨 **Infinite Canvas:** Sınırsız bir tuval üzerinde modüler yapılar oluşturun.[cite: 1]
- 🔌 **Extensible Node System:** Kendi mantık düğümlerinizi (Logic Nodes) ve veri dönüştürücülerinizi (Transformers) ekleyin.[cite: 1]
- ⚡ **Real-time API Testing:** İstekleri birbirine bağlayın, veriyi zincirleme olarak yönetin.[cite: 1]
- 🛠 **TypeScript First:** Tamamen tip güvenli mimari ile hatasız geliştirme süreci.[cite: 1]
- 🌑 **Ultra-Modern UI:** Glassmorphism etkileri, karanlık mod optimizasyonu ve akıcı animasyonlar.[cite: 1]

---

## 🚀 Başlangıç

### Gereksinimler
- Node.js (LTS sürümü tavsiye edilir)[cite: 1]
- npm veya yarn[cite: 1]

### Kurulum
```bash
# Depoyu klonlayın
git clone [https://github.com/kullanici-adi/vystra.git](https://github.com/kullanici-adi/vystra.git)

# Proje klasörüne gidin
cd vystra

# Bağımlılıkları yükleyin
npm install

# Geliştirme modunda başlatın
npm run dev
```[cite: 1]
